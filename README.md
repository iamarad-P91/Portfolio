## About the Project

This is a fully responsive coffee shop website built with **HTML**, **CSS**, and **JavaScript**. The project focuses on clean design, responsive layouts, and attention to small UI and UX details to provide a smooth user experience across different devices.

Although the project does not use a backend server, JavaScript is used to simulate the behavior of a real shopping website. Cart data is stored locally, allowing users to refresh the page without losing their selected items.

The website includes all the essential sections expected from a modern coffee shop, such as a product menu, shopping cart, responsive navigation, dark mode, and interactive elements. The code is organized, easy to read, and structured to demonstrate front-end development best practices.
